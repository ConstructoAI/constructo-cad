Liberation Sans 2.1.5 (Regular, Bold), metric-compatible with Arial.

Embedded in the WEB build only (src/scene/text/sysfont.rs): the browser has no system
fonts, so a drawing text style naming arial.ttf / arialbd.ttf fell back to the LFF stroke
font, wider than Arial, and table texts overflowed their cells. The desktop and server
builds keep using the installed fonts.
